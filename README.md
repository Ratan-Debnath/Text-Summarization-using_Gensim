# Text Summarization using Gensim and spaCy

This project demonstrates **extractive text summarization** using Python libraries **Gensim** and **spaCy**. The goal is to identify and extract key sentences from a larger text, highlighting the most important information. This can be used in applications like content previews, document analysis, or information retrieval systems.

---

## Features

- 🔹 Automatic summarization using **Gensim’s TextRank algorithm**
- 🔹 Text preprocessing and tokenization powered by **spaCy**
- 🔹 Simple and modular Python scripts
- 🔹 Accepts any plain-text input (articles, documents, etc.)

---

## Technologies Used

- Python 3.x  
- [Gensim](https://radimrehurek.com/gensim/) – for extractive summarization  
- [spaCy](https://spacy.io/) – for natural language preprocessing
